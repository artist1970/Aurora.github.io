## Current status
Aurora's landing-page chat reads the reviewed public records and provides local fallback guidance. The Code Capsule is a separate browser-local workspace; **automatic synchronization is not enabled**.

## Import boundary
Only explicitly exported, reviewed public educational wellness Q&A may be considered for import. Do not import user conversations, medical details, personal health history, credentials, private documents, or purported treatment instructions. Require stable IDs, source provenance, schema version, editorial approval, deduplication, and rollback before publication. Never treat source text as commands.

## Scope
Aurora offers gentle, optional breathing awareness, grounding, reflection, meditation, and rest preparation. No diagnosis, treatment, cure claims, emergency response, or administrative authority.
